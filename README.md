## Installing the NetClusterSim R Package

You can install the **NetClusterSim** R package directly from our public GitHub repository. Please follow the steps below.

### 1. Install the `remotes` package

If you do not already have the `remotes` package installed, run:

```r
install.packages("remotes")
```

### 2. Install NetClusterSim from GitHub

```r
remotes::install_github("uri-ncipher/NetClusterSim")
```

### 3. Load the package

```r
library(NetClusterSim)
```

The package is now ready to use.
